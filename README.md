# Terrarium

현실적인 변수(빛, 온도, 습도, 흙 수분, CO₂/O₂, 영양, 미생물, 동식물)로 움직이는 작은 생태계 시뮬레이션 게임.

- 기획서: [docs/PLAN.md](docs/PLAN.md)
- 생태계 지식 베이스(파라미터·출처): [docs/RESEARCH.md](docs/RESEARCH.md)

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 물리 공식 · 보존 법칙 · 헤드리스 시나리오 테스트
npm run build      # 타입체크 + 프로덕션 빌드
```

## 현재 상태: v0.3 (M0–M7)

유리병 속 생태계가 물리 → 생물 → 순환까지 연결되어 돌아갑니다. 물·탄소·질소 총량을 매 프레임 검산합니다(오차 ≈ 1e-13 kg).

- **환경**: 태양 위치·구름, 창턱/창가/방/LED, 온실효과, 습도·이슬점·김서림·물방울 흘러내림, 흙층 수분 이동(LECA 모세관 장벽), CO₂·O₂·CH₄, 계절
- **식물 8종**: 광합성·기공·증산·팽압(시듦)·질소(황화)·웃자람·번식, CAM 다육
- **이끼 2종**: 몸 수분이 공기와 평형(변수성), 마르면 휴면
- **흙 생태**: 낙엽 → 세균·곰팡이 → 원생생물·선충 → 암모늄 → 질산 → 식물 / 과습 시 탈질·H₂S·메탄·뿌리썩음
- **동물 9종**: 톡토기, 꼬마흰쥐며느리, 쥐며느리, 노래기, 달팽이, 지렁이, 포식 응애, 버섯파리, 물가파리
- **기타**: 유리 녹조막, 노란 버섯, 점균, 폭염·정전·해충 유입
- **게임**: 프리셋 5종(열대 밀폐형 / 바이오액티브 / 라티머의 병 / 건조형 / 빈 병), 심기·가지치기·동물 투입·낙엽·비료·칼슘, 도전 과제, "왜?" 원인 설명, 도감(출처 링크), 저장/불러오기, 타임랩스 녹화, 접사 카메라

## 구조

```
src/sim/        순수 TS 시뮬레이션 코어 (DOM 없음, 결정론적)
src/data/       재료·종 파라미터 JSON (출처와 confidence 포함)
src/worker/     시뮬레이션 Web Worker와 메시지 프로토콜
src/render/     Three.js 씬, 유리·응결 셰이더, 절차적 텍스처
src/ui/         그래프
tests/          Vitest
```
