# Terrarium

현실적인 변수(빛, 온도, 습도, 흙 수분, CO₂/O₂, 영양, 미생물, 동식물)로 움직이는 작은 생태계 시뮬레이션 게임.

- 기획서: [docs/PLAN.md](docs/PLAN.md)
- 생태계 지식 베이스(파라미터·출처): [docs/RESEARCH.md](docs/RESEARCH.md)

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 물리 공식 · 보존 법칙 · 헤드리스 시나리오 테스트
npm run build      # 타입체크 + 프로덕션 빌드
```

## 현재 상태: M1 (빈 병의 물리)

생물은 아직 없고, 병 속 **물리 환경**이 실시간으로 돌아갑니다.

| 변수 | 모델 |
|---|---|
| 햇빛 | 위도·날짜·시각에 따른 태양 위치, 구름(확률 과정), 창턱/창가/방 안/LED 배치 |
| 온도 | 공기·유리(8×12 조각)·뚜껑·흙 층의 열 네트워크, 온실효과, 증발/응결 잠열 (암시적 해법) |
| 습도 | 수증기 질량 수지, Magnus 식, 이슬점, VPD, 흙 수분활동도(Kelvin 식) |
| 응결 | 유리 조각별 물막 → 물방울 성장 → 흘러내림 → 흙으로 복귀 |
| 흙 수분 | van Genuchten–Mualem 층간 흐름 (LECA 배수층의 모세관 장벽 재현) |
| 가스 | 흙 호흡(Q10, 수분·산소 제한)으로 CO₂↑ O₂↓, 뚜껑 틈 환기, 열팽창에 의한 공기 출입 |
| 보존 장부 | 물·탄소 총량 오차를 매 프레임 표시 (≈1e-15 kg) |

조작: 시간 속도(최대 1일/초), 분무, 물 주기, 뚜껑(밀봉/유리/코르크/열림), 위치, 실내 온도.

## 구조

```
src/sim/        순수 TS 시뮬레이션 코어 (DOM 없음, 결정론적)
src/data/       재료·종 파라미터 JSON (출처와 confidence 포함)
src/worker/     시뮬레이션 Web Worker와 메시지 프로토콜
src/render/     Three.js 씬, 유리·응결 셰이더, 절차적 텍스처
src/ui/         그래프
tests/          Vitest
```
